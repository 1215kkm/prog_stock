# 용어 사전 (Glossary)

자동매매·트레이딩에서 자주 등장하는 한국어/영어 용어 정리.

---

## A. 매매 일반

| 용어 | 영문 | 설명 |
|---|---|---|
| 매수 | Buy / Long | 주식을 사는 것 |
| 매도 | Sell / Short(공매도) | 주식을 파는 것. 공매도는 빌려서 파는 것(개인 사실상 불가) |
| 진입 | Entry | 신규 매수해서 포지션 새로 잡는 것 |
| 청산 | Exit / Close | 보유 포지션을 팔아서 정리 |
| 손절 | Stop Loss | 손실 확대 방지를 위한 강제 매도 |
| 익절 | Take Profit | 이익 실현 매도 |
| 추격 매수 | Chase | 급등 종목을 따라 사는 행위 (대개 비추) |
| 물타기 | Averaging Down | 손실 종목 추가 매수로 평단가 낮추기 (이 시스템에서 **금지**) |
| 분할 매수 | Pyramiding (상승) / DCA (정기) | 여러 번 나눠 매수 |
| 평단가 | Average Cost | 매수 평균 단가 |
| 수익률 | Return | (현재가 - 평단가) / 평단가 |
| 실현 손익 | Realized P&L | 매도해서 확정된 손익 |
| 평가 손익 | Unrealized P&L | 보유 중인 종목의 미실현 손익 |

## B. 주문 유형

| 용어 | 영문 | 설명 |
|---|---|---|
| 시장가 | Market Order | 즉시 체결 가능한 가격으로 주문 |
| 지정가 | Limit Order | 지정한 가격 또는 더 좋은 가격에서만 체결 |
| 정정 주문 | Modify | 기존 미체결 주문의 가격/수량 변경 |
| 취소 주문 | Cancel | 미체결 주문 취소 |
| 슬리피지 | Slippage | 의도한 가격과 실제 체결가 차이 |
| 미체결 | Open / Pending | 주문은 냈지만 아직 체결 안 된 상태 |
| 부분 체결 | Partial Fill | 주문 수량 중 일부만 체결 |

## C. 시간/장 종류

| 용어 | 영문 | 설명 |
|---|---|---|
| 정규장 | Regular Session | 09:00~15:30 (한국) |
| 동시호가 | Call Auction | 단일가로 일괄 체결되는 시간대 |
| 시초가 | Opening Price | 09:00 시작가 |
| 종가 | Closing Price | 15:30 마감가 |
| 시간외 단일가 | After-Hours | 16:00~18:00 |
| 단일가 매매 | Single-Price Auction | 동시호가나 단기과열 종목에 적용 |
| 장중 | Intraday | 거래시간 안 |

## D. 가격 제한 / 시장 안전장치

| 용어 | 영문 | 설명 |
|---|---|---|
| 상한가 | Upper Limit | 일일 최대 상승가 (전일 종가 +30%) |
| 하한가 | Lower Limit | 일일 최대 하락가 (전일 종가 -30%) |
| VI | Volatility Interruption | 변동성 완화 장치 — 급변 시 2분 단일가 |
| 동적 VI | Dynamic VI | 직전 체결가 대비 발동 |
| 정적 VI | Static VI | 시초가 대비 발동 |
| 서킷브레이커 | Circuit Breaker | 지수 급락 시 거래 일시 중단 |
| 사이드카 | Sidecar | 선물 급변 시 프로그램 매매 일시 중단 |
| 단기과열 | Short-Term Overheating | 3일 이상 비정상 등락 → 단일가 |

## E. 종목 상태

| 용어 | 영문 | 설명 |
|---|---|---|
| 거래정지 | Trading Halt | 일시 거래 금지 |
| 관리종목 | Watchlist | 상장폐지 우려 종목 |
| 투자위험·경고·주의 | Investment Caution Levels | 위험도 단계별 경보 |
| 외국인 한도 | Foreign Ownership Limit | 일부 종목의 외국인 보유 상한 |
| 액면분할 | Stock Split | 1주를 N주로 (가격 1/N) |
| 액면병합 | Reverse Split | N주를 1주로 |
| 배당락 | Ex-Dividend | 배당 권리 마감 다음날 가격 조정 |
| 권리락 | Ex-Rights | 유상증자 권리 마감 후 조정 |
| 우선주 | Preferred Stock | 보통주 대비 의결권 X, 배당 우선 |

## F. 지표 / 분석

| 용어 | 영문 | 설명 |
|---|---|---|
| 이동평균 | Moving Average (MA) | 일정 기간 평균 가격선 |
| 50/150/200일선 | 50/150/200-day MA | 추세 판단용 핵심 MA |
| 신고가 | New High | 일정 기간 내 최고가 갱신 |
| 신저가 | New Low | 일정 기간 내 최저가 갱신 |
| 거래량 | Volume | 거래된 주식 수 |
| 거래대금 | Trading Value | 거래량 × 평균가 |
| RSI | Relative Strength Index | 과매수/과매도 지표 (0~100) |
| 볼린저밴드 | Bollinger Bands | 평균선 ± 2 표준편차 |
| MACD | Moving Average Convergence Divergence | 이동평균 차이 지표 |
| ATR | Average True Range | 평균 진폭 — 변동성 척도 |
| RS Rating | Relative Strength Rating | 시장 대비 상대 강도 (1~99) |
| VCP | Volatility Contraction Pattern | 미너비니의 변동성 수축 패턴 |
| 스테이지 1~4 | Stages 1-4 | 미너비니의 시장 사이클 4단계 |

## G. 펀더멘털

| 용어 | 영문 | 설명 |
|---|---|---|
| 매출 | Revenue / Sales | 회사가 판매한 금액 합계 |
| 영업이익 | Operating Income/Profit | 매출 - 매출원가 - 판관비 |
| 당기순이익 | Net Income | 모든 비용·세금 차감 후 이익 |
| EPS | Earnings Per Share | 주당순이익 = 순이익 / 발행주식수 |
| ROE | Return on Equity | 자기자본 대비 순이익 |
| ROA | Return on Assets | 총자산 대비 순이익 |
| YoY | Year-over-Year | 전년 동기 대비 |
| QoQ | Quarter-over-Quarter | 전분기 대비 |
| CAGR | Compound Annual Growth Rate | 연평균 성장률 |
| 시가총액 | Market Capitalization | 주가 × 발행주식수 |
| PER | Price-to-Earnings Ratio | 주가 / EPS |
| PBR | Price-to-Book Ratio | 주가 / 주당순자산 |
