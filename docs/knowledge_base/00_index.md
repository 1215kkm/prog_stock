# Knowledge Base Index

이 디렉터리는 **prog_stock 자동매매 시스템의 영구 지식 베이스**다. Claude Code 세션이 끝나도 사라지지 않도록 저장소에 커밋되며, `CLAUDE.md`가 매 세션 자동 로드해 핵심 룰이 잊히지 않도록 한다.

## 읽는 순서

1. **`02_user_philosophy.md`** — 이 시스템이 따르는 매매 철학. 모든 다른 결정의 기준이 된다.
2. **`01_strategy_canslim_sepa.md`** — 그 철학과 일치하는 검증된 프레임워크(오닐/미너비니) 요약.
3. **`03_korean_market_rules.md`** — 한국 시장의 특수 규칙. 위반하면 시스템이 작동 안 한다.
4. **`04_risk_management.md`** — 손절/사이징/MDD 룰북. 어떤 전략이든 이 게이트를 통과해야 주문 가능.
5. **`05_data_sources.md`** — KIS/DART/pykrx 사용법, 한도, 함정.
6. **`06_glossary.md`** — 용어 사전.
7. **`07_decision_log.md`** — 전략 변경/파라미터 조정 의사결정 기록 (시간 순).
8. **`08_reading_list.md`** — 추가 학습 자료.

## 문서 갱신 규칙

- **불변 원칙**(매매 철학, 손절 룰)은 변경 시 `07_decision_log.md`에 이유와 함께 기록.
- **수치 파라미터**(예: 손절 -7%, RS 임계 30%)는 백테스트 결과를 근거로 변경 가능. 단, 변경 시 백테스트 결과 링크와 함께 결정 로그에 남긴다.
- **새 자료를 학습**한 경우 해당 문서에 추가하고 `08_reading_list.md`에 출처 등록.

## 핵심 한 줄 요약

> 매출과 영업이익이 늘어나는 구간에서만 추세를 따라 매수하고, 둘 중 하나라도 꺾이면 즉시 손절한다. 바닥은 예측하지 않는다.
