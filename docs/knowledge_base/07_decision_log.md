# 의사결정 로그

전략 변경, 파라미터 조정, 아키텍처 결정의 시간 순 기록. 새 결정마다 **상단에 추가**(역시간 순).

---

## 형식

```
## YYYY-MM-DD — [짧은 제목]

**유형**: 전략 / 파라미터 / 아키텍처 / 운영
**결정자**: 이름 또는 시스템(자동)
**변경 전 → 변경 후**: ...
**근거**: 백테스트 결과 링크, 실험 노트북, 또는 외부 자료
**영향 범위**: 영향 받는 모듈/문서
**롤백 조건**: 어떤 결과가 나오면 되돌릴지
```
